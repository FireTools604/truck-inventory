If nothing shows up

  1. Check the status bar above is green. If not, tap it.
  2. Open the DWDemo app on the tablet and scan. If DWDemo reads the barcode, the scanner works and the problem is the browser profile.
  3. Open the DataWedge app → Profile0. Check the profile is enabled, Barcode input is on, and Keystroke output is enabled. If Chrome has its own profile, check that one instead.
  4. If data arrives but in pieces or with dropped characters, untick "Hide on-screen keyboard" above, or raise the inter-character delay in Keystroke output.
  5. If DataWedge is locked or Profile0 is disabled, it's an admin/MDM setting and the device owner will need to change it.
